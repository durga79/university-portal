## Abstract

This project presents the design and implementation of a secure role-based student management web application using Next.js 16, React 19, TypeScript, and PostgreSQL. The application demonstrates enterprise-level security practices including robust authentication, role-based authorization, comprehensive input validation, and protection against common web application vulnerabilities such as SQL injection, XSS, and CSRF attacks. The system supports two distinct user roles (Administrator and Student) with appropriate access controls and implements 15 security requirements with 100% completion. Testing was conducted through Static Application Security Testing (SAST) and functional security testing, with all test cases passing successfully.
